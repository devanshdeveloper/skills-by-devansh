# Visual Slop Reference

Compact catalog of generic visual decoration patterns generated by AI models and their exact non-destructive removal rules.

---

## Patterns & Removal Rules

### 1. Gradient Text Clipping (`visual-gradient-text`)
* **Detection**: Utility classes clipping background gradients into headline text (`bg-clip-text text-transparent bg-gradient-to-...`).
* **Rule**: Delete `bg-clip-text`, `text-transparent`, and gradient generator classes (`bg-gradient-to-[a-z]+`, `from-*`, `to-*`, `via-*`).
* **Fallback**: The element naturally inherits the clean solid foreground text color of its parent container.

### 2. Default Indigo/Purple Gradient Backgrounds (`visual-purple-gradient`)
* **Detection**: Cookie-cutter purple-to-indigo or violet decorative backdrop gradients (`from-purple-* to-indigo-*`, `from-violet-*`).
* **Rule**: Strip the gradient utility classes from the section or wrapper element.
* **Fallback**: Container falls back to clean flat surface colors or inherited background tokens.

### 3. Decorative Glow Blobs & Ambient Orbs (`visual-glow-blob`)
* **Detection**: Floating, absolutely positioned circular divs with extreme blur (`blur-3xl`, `blur-2xl`), low opacity (`opacity-10`, `opacity-20`), and `pointer-events-none` layered solely for ambient color glow.
* **Rule**: Delete the decorative glow `<div>` or `<span>` container element entirely.
* **Fallback**: Normal unblemished layout background.

### 4. Blanket Glassmorphism Surfaces (`visual-glassmorphism`)
* **Detection**: Indiscriminate layering of `backdrop-blur-*`, translucent white or dark backgrounds (`bg-white/10`, `bg-black/20`), and hairline translucent borders (`border-white/20`).
* **Rule**: Delete `backdrop-blur-*` and translucent background/border classes.
* **Fallback**: Use the project's standard solid card background and standard border.

### 5. Raw Emoji Used as Icon Stand-ins (`visual-emoji-icon`)
* **Detection**: Raw Unicode emoji glyphs (`🚀`, `✨`, `💡`, `🔥`, `⚡`) placed inside feature headers, buttons, or list bullets in place of purposeful SVG icons.
* **Rule**: Delete the emoji glyph. If an icon is functionally required for usability, leave the element untouched and log it under "Needs a Human".

### 6. Stacked Heavy Shadow & Extreme Radius (`visual-stacked-radius-shadow`)
* **Detection**: Simultaneous application of heavy drop shadows (`shadow-2xl`, `shadow-xl`) and extreme rounding (`rounded-2xl`, `rounded-3xl`) across every card or button.
* **Rule**: Strip the heavy shadow class (`shadow-2xl`, `shadow-xl`). Retain standard border radius.

### 7. Generic Floating Announcement Pills (`visual-announcement-pill`)
* **Detection**: Floating decorative pill badges displaying generic filler labels like "✨ AI-Powered", "🚀 Next-Gen", or "Introducing Beta".
* **Rule**: Delete the announcement badge element.

### 8. Gratuitous Hover Lift/Scale on Static Cards (`visual-hover-lift`)
* **Detection**: `hover:-translate-y-1`, `hover:scale-105`, and `transition-all` placed on informational, non-clickable card containers.
* **Rule**: Remove the hover transformation and transition classes.

### 9. Purposeless Infinite Marquees (`visual-marquee`)
* **Detection**: Infinite scrolling text or logo marquees that endlessly loop duplicate items with zero interaction.
* **Rule**: Delete the marquee container element.
